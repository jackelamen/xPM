# User Manuals

Complete, design-matched user manuals for both the Admin Portal and Client Portal applications.

## Files Included

### 1. **index.html** - Manual Directory
Landing page with links to both manuals. Start here to access either manual.

- **Design:** Balanced professional layout with cards linking to each manual
- **Content:** Overview and navigation to both portals

### 2. **admin-portal-manual.html** - Admin Portal User Manual
Complete guide for internal administrators managing projects, teams, and operations.

**Sections:**
- Getting Started (login, interface layout)
- Dashboard Overview (KPIs, recent activity, status indicators)
- Managing Projects (creation, details, timeline, phases, status types)
- Task Management (creating tasks, status tracking, workload view)
- Team Management (adding members, roles, spaces, workload)
- Settings & Configuration (organization settings, user profile, data/privacy)
- Troubleshooting & Support (common issues, getting help)

**Design:** 
- Font: Hanken Grotesk (matches admin app)
- Colors: Emerald green accent (#059669), professional light theme
- Style: Dense, operational, information-focused

### 3. **client-portal-manual.html** - Client Portal User Manual
Complete guide for clients viewing projects, deliverables, and billing.

**Sections:**
- Getting Started (login, interface layout, first time setup)
- Dashboard & Overview (active projects, recent activity, status indicators)
- Understanding Your Projects (viewing details, phases, timeline, communication)
- Deliverables & Documents (accessing, reviewing, providing feedback)
- Billing & Invoices (viewing, downloading, disputing, payment terms)
- Communication & Updates (messages, notifications, preferences)
- Account Settings (profile, password, 2FA, notification settings)
- FAQ & Support (common questions, troubleshooting, getting help)

**Design:**
- Font: Geist (matches xPortal client app)
- Colors: Indigo accent (#5b48ee), clean light theme with editorial serif title
- Style: Client-focused, accessible, clear hierarchy
- Special: One serif moment per page (h1 title) for premium feel

## How to Use

### Viewing the Manuals

1. **Open in Browser:** Double-click any HTML file or right-click and select "Open with Browser"
2. **Start with Index:** Open `index.html` for a directory with links to both manuals
3. **Direct Access:** Open specific manuals directly:
   - Admin: `admin-portal-manual.html`
   - Client: `client-portal-manual.html`

### Navigation

Each manual includes:
- **Table of Contents:** Quick links to all major sections at the top
- **Internal Links:** Click any section heading to jump directly there
- **Smooth Scrolling:** Built-in smooth scroll behavior for navigation

### Printing & Exporting

**To Print:**
1. Open the manual in your browser
2. Press `Ctrl+P` (Windows) or `Cmd+P` (Mac)
3. Click "Print"

**To Save as PDF:**
1. Open the manual in your browser
2. Press `Ctrl+P` (Windows) or `Cmd+P` (Mac)
3. Select "Save as PDF" from the Destination dropdown
4. Click "Save"

**Recommended Print Settings:**
- Page Size: Letter or A4
- Margins: Default (0.5")
- Background Graphics: Enabled (to preserve colors)

### Responsive Design

All manuals are fully responsive:
- **Desktop:** Full layout with optimal reading width
- **Tablet:** Adjusted spacing and grid layouts
- **Mobile:** Single column, touch-friendly, readable text
