About These Manuals

These user manuals provide comprehensive documentation for both the Admin Portal and Client Portal applications. Each manual is designed to match the look and feel of its respective application and includes:

  • Getting Started: Login instructions and interface overview
  • Feature Guides: Detailed instructions for each major feature
  • Step-by-Step Tutorials: Visual walkthroughs of common tasks
  • Reference Tables: Status definitions, roles, and configurations
  • Troubleshooting: Common issues and solutions
  • FAQ: Answers to frequently asked questions

How to Use These Manuals

Viewing: Click on a manual above to open it in your browser. The manual is fully responsive and works on desktop, tablet, and mobile devices.

Navigation: Each manual includes a quick navigation menu at the top for easy access to sections.

Printing: You can print any manual directly from your browser. Use File → Print or press Ctrl+P (Windows) / Cmd+P (Mac).

Exporting: To save as PDF, use your browser's print dialog and select "Save as PDF" as the destination.
